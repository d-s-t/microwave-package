Parameters

A box with one value pins that parameter for the run; a box with several values sweeps it. Leave a box empty to keep the parameter at the equation file's own value, which is what the box shows in grey. Syntax: a single number ("4"), a comma list ("0,2,4,6,8,10"), or start:stop:step ("0:10:2"). More than one box holding a range sweeps every combination of them (cartesian product) -- watch the combination count, since each one is a full model build + analysis. Click a drawing to see which dimension a parameter drives.
