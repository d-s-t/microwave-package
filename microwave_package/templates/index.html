Parameters

A box with one value pins that parameter for the run; a box with several values sweeps it. Leave a box empty to keep the parameter at the equation file's own value, which is what the box shows in grey. Syntax: a single number ("4"), a comma list ("0,2,4,6,8,10"), or start:stop:step ("0:10:2"). More than one box holding a range sweeps every combination of them (cartesian product) -- watch the combination count, since each one is a full model build + analysis. Bare board

Tick to simulate only the PCB and its connectors (no_chip = 1): a straight 50 Ω CPW from one SMP to the other, with no die, opening, pedestal, bond pads or wire bonds. It separates what the board and connectors do from what the chip does. Applies to the whole run. The bond-finger and chip reference planes do not exist without a chip.

Corner screws

Tick to hold the lid, PCB and box together with four M2 countersunk screws at the PCB corners (screws_on = 1), with their holes in all three parts. They stand as metal posts in the corners of the cavity, so this changes the box modes; build a run with and without to see by how much. Their dimensions are in the “Corner screws” group above.

Distortions

The clean geometry has no distortions (no_distortion = 1); the distorted variant adds distortions to the box and holes to the PCB (no_distortion = 0). Pick one for the whole run, or build every combination both ways.

Machine

Also decides when results appear: with the worker on its own machine each combination is post-processed as soon as it finishes, instead of waiting for the whole sweep. Untick it when the worker runs here, so the two do not compete for the same AEDT.


Geometry source

With this on, every combination rebuilds the boards from the equations file and the model carries real copper, vias and shielding. With it off you get the older SolidWorks-only geometry: no copper, and a far lighter mesh.

Materials / boundaries

Pick a common material from each list, or "Custom..." to type any exact HFSS library name.

{{ material_field('mat_box', 'Box material', material_options.mat_box) }} {{ material_field('mat_pcb', 'PCB material', material_options.mat_pcb) }} {{ material_field('mat_chip', 'Chip material', material_options.mat_chip) }} {{ material_field('mat_vacuum', 'Vacuum material', material_options.mat_vacuum) }}

The box is aluminium, which is superconducting below about 1.2 K, so perfect E is the right default. It puts mode and dip positions in the right place but exaggerates dip depth and Q, because nothing is lost in the walls. With it off, the box and lid get a finite-conductivity boundary of this value instead -- about 1e8 S/m for 6061 at liquid-helium temperature (3.8e7 at room temperature).

{{ material_field('mat_conductor_pcb', 'PCB conductor', material_options.mat_conductor_pcb) }} {{ material_field('mat_conductor_chip', 'Chip conductor', material_options.mat_conductor_chip) }}

Leave the conductor boxes on perfect E unless you have a cryogenic surface impedance to hand: HFSS's stock copper and niobium are room-temperature normal-state values, which at millikelvin are less realistic than PEC. The SMP connector is not covered by this: its metal is fixed to brass and its bead to LCP, from the vendor datasheet, with no perfect-E boundary.


Untick to build the model with no wire bonds at all -- the die is left unbonded. Everything else is unchanged: the board and die still carry the same bond pads, only the wire itself is left out. A bonder loads one wire at a time, gold or aluminum. Like the rest of the conductors, the wire is perfect E while "Perfect E on the conductors" is ticked, so its material only matters with that off.
